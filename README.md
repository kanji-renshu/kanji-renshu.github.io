# かんじ れんしゅう

小学校で習う1026字（漢字検定10級〜5級相当）の書き順・読み・かきとりを練習するアプリです。
HTML 1枚（`index.html`）で動作し、iPad + Apple Pencil での練習に対応しています。

公開URL: https://kanji-renshu.github.io/

（2026-11-23 に https://jyz002xyz.github.io/kanji-renshu/ から移転しました。旧URLを開くと、記録を引き継いでこちらへ移れます。）

## 主な機能
- 級ごとの漢字一覧、書き順アニメーション、読み・意味・熟語・部首の解説
- なぞりがき／おてほんなしの1画ずつの判定（書き順・向きのチェック）
- かきとりテスト（ことばの意味つき）、にがて漢字の復習
- アバター（キャラ）作成、ポイント・ショップ、ログインボーナス、ミッション、バッジ、きせつのイベント
- 記録のバックアップ（ファイル・ひきつぎコード）

## プライバシー
- 学習記録・キャラ・ニックネーム・設定は、端末のブラウザ（localStorage）だけに保存し、サーバーへ送信しません。
- 広告・アクセス解析は使っていません。通信はアプリ本体の読み込みと、同じサイトの `version.json`（更新確認）の取得のみです。
- GitHub Pages で配信しているため、アクセス時に GitHub がIPアドレス等を記録することがあります（GitHub のプライバシー方針による）。

## セキュリティ
- 外部スクリプト・外部ライブラリ・CDN は使っていません。
- Content-Security-Policy（meta）で、スクリプトはビルド時のハッシュ値と一致するものだけ実行を許可し、通信先は同じサイトに限定しています。
- バックアップの読み込み時は、すべての値を許可された選択肢・数値に限定して取り込みます。

## ソースコード

アプリのソースとビルド手順は [`src/`](src/) にあります。`python3 src/build.py` で、公開中の `index.html` と同じものを作れます（くわしくは `src/README.md`）。
